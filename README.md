# Benevolat

This project a été généré avec [Angular CLI](https://github.com/angular/angular-cli) version 17.2.3 et le serveur Node.js version 20.12.2

## Description

C’est un projet ouvert pour la gestion de n'importe quel bénévolat (Loisirs, vente, arrangement, ect…). Les différents utilisateurs seront la possibilité aux clients clients de commander leur produit souhaité, les distributeurs qui peuvent être des bénévoles ou pas, des gestionnaires de produits et le directeur qui guide les autres.  
 

## Démarrer le projet
1. Connexion avec la bd MYSQL(Xampp, workbench, ect...)  réussi (les requêtes de création et d'insértion sont dans
   ./BenevoleProjectPlan\Sqls\test)
2. Commandes : 
    - Dans le backend Node.js :
       o npm run dev
    - Dans le front end Angular :
       o ng serve
